- 2026-04-22 — Deep-link highlight on `/human-knowledge?focus=<systemPath>`: made the landing highlight both more visible and longer-lived, fixed a latent bug that prevented it from clearing at all, and removed a Pink inset left-edge on the resting state per user request.
